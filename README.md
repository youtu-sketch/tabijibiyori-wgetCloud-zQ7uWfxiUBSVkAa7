## 前言


每年春节大家必备的抢票工具Bypass\-分流抢票。分流抢票是一款免费无广适用于PC端的自动分流抢票软件。


分流抢票，是以用户为中心、人性化的抢票软件。不做广告、不做推广、不携带病毒、不收集隐私信息，并接受各方技术评测，全心全意为用户打造一款属于自己的抢票软件。


## 项目介绍


分流抢票是一款完全免费的抢票软件，全程自动抢票、自动抢候补、整点抢预售、稳定捡漏。


支持多天、多车次、多席别、多乘客、多站查询、多任务等功能，支持各种提醒、选座和选铺、改签刷票、增开监控，自动支付等。

## 项目技术


**开发框架**


本项目基于 .NET Framework 4\.5\.2 开发，确保了良好的兼容性和稳定性。


**推荐系统环境**


建议使用 Windows 10 或 Windows 11，并保持系统的及时更新。


最新的操作系统版本通常包含更多的安全补丁和功能改进，有助于提升软件的稳定性和安全性。


**安装与运行指南**


1、Windows 10/Windows 11 用户


无需额外安装，可直接打开应用程序。


如果遇到无法启动的情况，请尝试重新下载最新版本的应用程序。


2、Windows 7/Windows 8/Windows 8\.1 用户


确认系统已安装 .NET Framework 4\.5\.2 或更高版本，可以直接运行应用程序。


如果缺少 .NET Framework，请下载并安装 Microsoft .NET Framework 4\.5\.2。


[https://download.microsoft.com/download/E/2/1/E21644B5\-2DF2\-47C2\-91BD\-63C560427900/NDP452\-KB2901907\-x86\-x64\-AllOS\-ENU.exe](https://github.com)


若在安装过程中遇到问题，建议下载并使用 分流抢票提供的 .NET 4\.8 辅助安装工具，以确保顺利完成安装。

3、Windows XP 用户


由于 12306 已不再支持 TLS 1\.0，Windows XP 系统将不再提供支持。


建议升级到 Windows 10 或更高版本以继续使用分流抢票服务。


停止对 XP 的支持不仅提高了系统的安全性，也为软件开发带来了更多的可能性和创新空间。

**1、查询余票**


输入出发地\-目的地,选择乘车日期,查询余票，即加载到列表。

选择乘车人\-席别\-车次,建议多选车次和席别,增大成功的几率。


![](https://img2024.cnblogs.com/blog/576536/202501/576536-20250113105305135-564770351.png)

整点抢票,修改查询间隔，捡漏则默认不修改间隔,点击开始刷票。

## 项目说明


2024年12月：抢票的进一步收紧


1、随着去年风控的升级，识别到异常特征并不会踢出，而是放在排队队列中处理，排队是必须的过程，但不能提前知道真没票还是被识别了。


2、更重要的是官方APP排队时间相比官网更短，可能是官网被降权了，优先级不如官方APP，而软件基于官网，预售还是用官方APP手动抢吧。


4、除此之外，高峰期放票越来越少，很多地方只放候补，以前是区间不放，现在全程也不放，所以一定要第一时间候补并支付，排名很重要。


5、官方上线了预填单试点，这才是预售抢票的大杀器，被称之为官方抢票，如果你的行程在这个范围，建议提交预填单，未来很可能是它的。
